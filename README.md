# sobes.local - шпаргалка для собеса (PHP/Symfony, финтех + фуллстек)

Сервис-шпаргалка: **655 карточек** вопрос-ответ по **31 теме**, мгновенный поиск в браузере, тёмная тема. Открывается на **https://sobes.local**.

Данные лежат в **PostgreSQL**, отдаются через тонкий **PHP-API** с кэшем в **Redis**. Фронт грузит всё одним запросом и ищет прямо в браузере - поэтому быстро, как раньше. Правки и закрепы сохраняются в БД.

## Как открыть

Всё поднято в Docker, домен уже в `/etc/hosts`, TLS через общий nginx-proxy. Просто открой **https://sobes.local**.

Если домен не резолвится:
```bash
echo "127.0.0.1 sobes.local" | sudo tee -a /etc/hosts
```

## Архитектура

- **Postgres** (`sobes-postgres`) - источник правды: таблицы `categories`, `questions` (q/a/detail/code/tags/weight/pinned/edited/orig), `settings` (личные заготовки).
- **Redis** (`sobes-redis`) - кэш собранного JSON всех карточек; сбрасывается при любой правке.
- **PHP-API** (`sobes-php`, php-fpm без фреймворка, PDO + phpredis) - `api/index.php`:
  - `GET /api/cards` - все карточки одним JSON (из Redis).
  - `POST /api/cards/{id}/pin {pinned}` · `POST /api/pins/clear` - закрепы.
  - `PATCH /api/cards/{id}` - правка q/a/detail/code · `POST /api/cards/{id}/reset` - вернуть оригинал.
- **nginx** (`sobes-web`) - отдаёт статику `public/`, роут `/api/` → php-fpm. В сети `proxy-network` (для общего reverse-proxy) + внутренней `sobes-internal`.
- **Фронт** (`public/`, без сборки): `api.js` (клиент), `search.js` (движок), `app.js` (UI). Грузит `/api/cards` один раз, **поиск и сортировка - в браузере** (доли мс). Правки/закрепы - оптимистично: UI меняется сразу, запись в БД в фоне.

## Возможности

- **Короткий + развёрнутый ответ**: виден короткий ответ, по **«Подробнее»** / **Enter** раскрывается развёрнутый (простыми словами) + код. Определения — по строкам.
- **Вес (популярность)**: у каждого вопроса `weight` 1-100. В категориях сортировка по весу (сверху то, что чаще спрашивают), в поиске вес подмешан к релевантности.
- **Главная = закреплённые**: без выбранной категории и поиска показываются только закреплённые. **Поиск ищет по всем**.
- **Закрепы** 📌 и **правка** (карандаш: вопрос / короткий / развёрнутый / код, «Вернуть оригинал») — **сохраняются в БД**, переживают перезагрузку и общие для всех устройств. «Снять все закрепы» — в футере.
- **Поиск универсальный**: морфология (стемминг), раскладка RU↔EN (`nhfypfrwbb`→"транзакции"), транслит (`докер`→docker), поиск по вопросу/ответу/detail/коду/тегам, опечатки.
- **Личные заготовки**: кнопки «Расскажи о себе» / «Сложная задача» → попап. Текст в БД (`settings`), правится прямо в попапе (карандаш).

Вопросы и personal редактируются в приложении и каноничны в БД. Категории в UI не редактируются (управляются на бэке через API `PATCH /categories/{key}` и `POST /categories/reorder`, начальный порядок — `db/categories.json`). Пересид вопросов (`seed.php`) правки категорий/personal НЕ затирает — `db/*.json` только первичный бутстрап.

## Клавиатура

- `/` или `Cmd/Ctrl+K` - поиск · `↑ ↓` - навигация · `Enter` - развернуть подробный ответ · `Esc` - сброс, повторный - «Все категории».

## Управление и наполнение (всё в Docker)

```bash
docker compose up -d --build     # поднять/пересобрать весь стек
docker compose exec php php /var/www/api/seed.php   # (пере)залить данные в БД из parts/*.json
docker compose down              # остановить (данные БД в volume sobes-pgdata сохраняются)
```

Бэкапить/восстанавливать через `docker exec sobes-postgres pg_dump/psql`.

### Массовое обновление контента

Точечно правь карточки прямо в UI (карандаш) — уходит в БД. Массово (много вопросов сразу):
1. правь `public/data/parts/<тема>.json` (`{q, a, detail, code, tags, weight}`);
2. перезалей: `docker compose exec php php /var/www/api/seed.php` (перезапишет БД из файлов).

Порядок и названия категорий - `db/categories.json`.
